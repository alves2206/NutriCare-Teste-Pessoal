# Integração futura com IA

Este módulo está reservado para a futura interpretação de refeições em linguagem natural.

Regras planejadas:

- A IA deverá interpretar apenas alimento, quantidade, unidade e tipo de refeição.
- Calorias e nutrientes continuarão sendo calculados pelo sistema com base nos alimentos cadastrados.
- A futura rota deverá executar no servidor.
- Chaves de API nunca devem ser expostas no navegador.
